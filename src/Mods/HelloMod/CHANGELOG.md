# Changelog - Milex GMS1 HelloMod

All notable changes to the `Milex GMS1 HelloMod` demonstration plugin.
This format is based on [Keep a Changelog](https://keepachangelog.com/).

---

## [1.1.0] - 2026-08-29

### Added

- **Multi-Language Support**:
  - Automatic localization of menu strings and log output for English and German.
- **In-Game Menu Integration**:
  - Rebindable hotkey, customizable greeting message, and live enable/disable toggle.

---

## [1.0.0] - 2026-08-29

### Initial Release

- Initial demonstration mod with customizable hotkey (`F2`) and configurable greeting message.
